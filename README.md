# ALESwiftToolkit

A collection of reusable Swift components, utilities and micro-modules extracted from real production projects.  
This repository is intended as a lightweight toolkit for rapid development, code sharing and experimentation.

The goal is to gather small, well-written building blocks that can be reused across multiple iOS apps, helping to speed up development and maintain clean, consistent code.

### Contents
- 📦 Reusable UI components
- 🧩 Utilities and helpers
- 🗃 Core Data helpers
- 🔌 Extensions
- 🧪 In App Purchase
- And more...


### Objective
Personal toolkit with ready to use components and technical experiments.
